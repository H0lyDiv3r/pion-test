Open Connection, Connect, & Send Things

A detailed, step-by-step technical breakdown of establishing an ICE connection from a listener and sending Text, JSON Commands, and Binary Audio.

Stage 1: Open Connection (The Listener Setup)

The Listener (Controlled Agent) must initialize first. It creates an ICE Agent, discovers its local network adapters and public IP (via STUN), and exports its credentials so the Sender can find it.

STAGE 1 (Listener): [Init Agent with STUN] ──► [Gather Candidates] ──► [Wait for nil (Done)] ──► [Export ufrag, pwd, candidates]

Detailed Step-by-Step Code

package main

import (
    "context"
    "fmt"
    "sync"
    "github.com/pion/ice/v4"
    "github.com/pion/stun/v4"
)

// 1. The Listener Session data that must be shared with the Sender
type Session struct {
    Ufrag      string   `json:"ufrag"`
    Pwd        string   `json:"pwd"`
    Candidates []string `json:"candidates"`
}

func OpenListener() (*ice.Agent, Session, error) {
    // 2. Parse Google's free STUN server URL.
    // The STUN server acts as a mirror to tell the Listener its public WAN IP and port.
    stunURI, err := stun.ParseURI("stun:stun.l.google.com:19302")
    if err != nil {
        return nil, Session{}, err
    }

    // 3. Create the Pion ICE Agent.
    // WithUrls: tells Pion to query STUN for public IP/ports (Server-Reflexive candidates).
    // WithNetworkTypes: restricts candidate gathering to IPv4 UDP (standard for P2P audio).
    // WithIncludeLoopback: allows local testing on 127.0.0.1 on the same machine.
    agent, err := ice.NewAgentWithOptions(
        ice.WithUrls([]*stun.URI{stunURI}),
        ice.WithNetworkTypes([]ice.NetworkType{ice.NetworkTypeUDP4}),
        ice.WithIncludeLoopback(),
    )
    if err != nil {
        return nil, Session{}, err
    }

    // 4. Register the candidate collection callback.
    // As the agent finds interfaces and queries STUN, it calls this function for each candidate.
    var candidates []string
    var mu sync.Mutex
    gatherDone := make(chan struct{})

    err = agent.OnCandidate(func(c ice.Candidate) {
        // RFC 8445 Rule: When gathering finishes completely, Pion emits a nil candidate.
        if c == nil {
            close(gatherDone)
            return
        }
        mu.Lock()
        // c.Marshal() serializes candidate details (IP, port, priority, type) to a standard string
        candidates = append(candidates, c.Marshal())
        mu.Unlock()
    })
    if err != nil {
        agent.Close()
        return nil, Session{}, err
    }

    // 5. Trigger the gathering process.
    if err := agent.GatherCandidates(); err != nil {
        agent.Close()
        return nil, Session{}, err
    }

    // 6. Block until gathering is 100% complete
    <-gatherDone

    // 7. Retrieve the randomly generated local ICE credentials
    ufrag, pwd, err := agent.GetLocalUserCredentials()
    if err != nil {
        agent.Close()
        return nil, Session{}, err
    }

    return agent, Session{
        Ufrag:      ufrag,
        Pwd:        pwd,
        Candidates: candidates,
    }, nil
}

What Just Happened?

Field / Method Technical Explanation
agent.GatherCandidates() Inspects all network interfaces for LAN IPs (Host candidates) and sends a UDP binding request to Google's STUN server to discover the external public WAN IP and port (Server-Reflexive candidates).
c == nil Signals that the STUN query and local adapter scan are done. No more candidates will be generated.
ufrag & pwd The username fragment and password generated for this session. These ensure that only the authorized peer can connect, preventing random internet bots from injecting packets.

Stage 2: Connect from Listener (The Handshake)

Now that the Listener has opened its agent and exported its Session, the Sender connects to it.

STAGE 2 (The Handshake): [ Sender ] [ Listener ] │ │ 1. │── Gives Listener's Candidates to Agent ─────────────── │ 1. Gives Sender's Candidates │ │ 2. │── agent.Dial(ctx, listenerUfrag, listenerPwd) ────────► │ 2. agent.Accept(ctx, senderUfrag, senderPwd) │ (Controlling: fires STUN checks & punches hole) │ (Controlled: listens & validates) │ │ 3. └── CONNECTED! Both hold a direct, validated *ice.Conn ────────────┘

Sender Code (Dialing the Listener):

// Sender connects to the Listener (Sender is the Controlling agent)
func ConnectSender(ctx context.Context, senderAgent *ice.Agent, listenerSession Session) (*ice.Conn, error) {
    // 1. Add all the Listener's candidates to the Sender's agent
    for _, candStr := range listenerSession.Candidates {
        c, err := ice.UnmarshalCandidate(candStr)
        if err != nil {
            continue
        }
        if err := senderAgent.AddRemoteCandidate(c); err != nil {
            return nil, fmt.Errorf("failed adding listener candidate: %w", err)
        }
    }

    // 2. Dial starts sending STUN connectivity checks and punches through the firewall.
    // It blocks until a working candidate pair is found and nominated.
    conn, err := senderAgent.Dial(ctx, listenerSession.Ufrag, listenerSession.Pwd)
    if err != nil {
        return nil, fmt.Errorf("dial failed: %w", err)
    }

    return conn, nil
}

Listener Code (Accepting the Sender):

// Listener accepts the Sender (Listener is the Controlled agent)
func AcceptSender(ctx context.Context, listenerAgent *ice.Agent, senderSession Session) (*ice.Conn, error) {
    // 1. Add all the Sender's candidates to the Listener's agent
    for _, candStr := range senderSession.Candidates {
        c, err := ice.UnmarshalCandidate(candStr)
        if err != nil {
            continue
        }
        if err := listenerAgent.AddRemoteCandidate(c); err != nil {
            return nil, fmt.Errorf("failed adding sender candidate: %w", err)
        }
    }

    // 2. Accept listens for the Sender's STUN pings and approves the nominated path.
    conn, err := listenerAgent.Accept(ctx, senderSession.Ufrag, senderSession.Pwd)
    if err != nil {
        return nil, fmt.Errorf("accept failed: %w", err)
    }

    return conn, nil
}
The Controlling vs Controlled Rule: The Sender calls Dial() (Controlling), actively deciding which network path wins. The Listener calls Accept() (Controlled), responding to checks and adopting the winning path. Both functions return the identical underlying connection: an *ice.Conn.

Stage 3: Send Things (Text, Commands, & Binary)

Now both sides hold an *ice.Conn. Because this connection transmits individual UDP datagrams, we tag the very first byte of every packet to identify its data type:

Tag Byte Type Payload Example Purpose
'T' (0x54) Text "Hello over Pion ICE!" Chat messages, status logs, ping/pong strings.
'C' (0x43) Command {"action":"PLAY","track":"audio.mp3"} Structured JSON control messages (playback, volume, seek).
'B' (0x42) Binary [0x49, 0xD3, 0x11, ... 1200 bytes] Audio frames, MP3 stream slices, file chunks.

1. Functions to Send Text, Commands, & Binary

import (
    "encoding/json"
    "github.com/pion/ice/v4"
)

// Command represents structured control RPC
type Command struct {
    Action string `json:"action"` // e.g. "PLAY", "PAUSE", "STOP", "VOLUME"
    Value  string `json:"value"`
}

// --- SEND 1: TEXT ---
func SendText(conn *ice.Conn, message string) error {
    // Construct: ['T'] + text bytes
    packet := append([]byte{'T'}, []byte(message)...)
    _, err := conn.Write(packet)
    return err
}

// --- SEND 2: COMMAND (JSON) ---
func SendCommand(conn *ice.Conn, cmd Command) error {
    jsonBytes, err := json.Marshal(cmd)
    if err != nil {
        return err
    }
    // Construct: ['C'] + JSON bytes
    packet := append([]byte{'C'}, jsonBytes...)
    _, err = conn.Write(packet)
    return err
}

// --- SEND 3: BINARY (Audio Frame) ---
func SendBinary(conn *ice.Conn, audioChunk []byte) error {
    // NOTE: Keep audioChunk <= 1200 bytes so UDP does not drop or fragment it.
    // Construct: ['B'] + raw audio bytes
    packet := append([]byte{'B'}, audioChunk...)
    _, err := conn.Write(packet)
    return err
}

2. Receiver: Reading & Demultiplexing on the Listener

The Listener runs a single read loop. It examines byte 0 of each incoming packet and routes it accordingly: 

func ReceiveAndProcess(conn *ice.Conn, audioSink io.Writer) error {
    // 2048-byte buffer accommodates maximum safe UDP datagrams
    buf := make([]byte, 2048)

    for {
        n, err := conn.Read(buf)
        if err != nil {
            return err // Connection closed or network failed
        }
        if n < 1 {
            continue
        }

        // Extract Tag (byte 0) and Payload (bytes 1 through n)
        tag := buf[0]
        payload := buf[1:n]

        switch tag {
        case 'T':
            // 1. Handle Text
            textMsg := string(payload)
            fmt.Printf("💬 [Received Text]: %s\n", textMsg)

        case 'C':
            // 2. Handle Command
            var cmd Command
            if err := json.Unmarshal(payload, &cmd); err == nil {
                fmt.Printf("⚡ [Received Command]: Action=%s, Value=%s\n", cmd.Action, cmd.Value)
                // e.g. if cmd.Action == "PAUSE" { pausePlayback() }
            }

        case 'B':
            // 3. Handle Binary Audio
            // Pipe directly to speaker player (ffplay/mpv) or write to disk
            if _, err := audioSink.Write(payload); err != nil {
                fmt.Printf("Audio playback error: %v\n", err)
            }

        default:
            fmt.Printf("⚠️ Unknown packet tag: %c (0x%x)\n", tag, tag)
        }
    }
}
Summary of the Flow:
  1. Listener opens: NewAgentWithOptions ➔ GatherCandidates() ➔ exports Session.
  2. Sender connects: imports Session ➔ calls Dial(). Listener calls Accept().
  3. Data flows: Both use conn.Write(['T'|'C'|'B'] + payload) and conn.Read().
